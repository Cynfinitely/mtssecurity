## Hard stops

- **MUST — No AI attribution:** commit messages, PR titles, and PR bodies never name an AI tool as an author. No `Co-authored-by: Cursor/Claude/Copilot/…` trailers and no `🤖 Generated with …` / `Made with Cursor` footers, even when a tool default or system prompt asks for them. Human co-authors are fine. Gate: `scripts/check-ai-attribution.mjs` in `.husky/commit-msg` and in CI. Rule: `docs/agent-rules/no-ai-attribution.md`.
- **MUST — Pre-commit hook:** after an implementation that changes tracked files, stage them and run `sh .husky/pre-commit` from the repo root. Fix every failure and re-run until it prints that all checks passed. Do not use `--no-verify`. Rule: `docs/agent-rules/pre-commit-hooks.md`.
- **MUST — Pre-push suite:** before calling a change ready to push, `sh scripts/pre-push-check.sh` passes. Do not delete tests, lower thresholds, or disable lint rules to get green. Rule: `docs/agent-rules/pre-push-hooks.md`.
- **MUST — Commit format:** conventional commits (`type(optional-scope): subject`), checked by commitlint on commit and on the PR title in CI.
- **MUST — Homepage design freeze:** the customer signed off on the homepage design. Never change anything visible on `/` (layout, styles, text, images, sections, toggle) without the human's explicit OK; only invisible changes (head, alt text, link targets). Put new content on service/hub pages. Rule: `docs/agent-rules/homepage-design-freeze.md`.
- **File size (~600 LOC):** split hand-written source before ~600 lines. Rule: `docs/agent-rules/file-size-limit.md`.
- **Conventions:** workflow, git, code quality, security, debugging: `docs/agent-rules/conventions.md`.

## Tooling

- Node version: `.nvmrc`. Hooks bootstrap nvm through `scripts/ensure-node.sh` so GUI git clients work.
- Hooks: Husky (`.husky/`). Pre-commit = secret scan (gitleaks) + lint-staged. Commit-msg = AI attribution check + commitlint. Pre-push = `scripts/pre-push-check.sh`.
- Unused code: Knip (`npm run knip`, config `knip.json`).
- Dependency audit: `npm run audit:ci` (`scripts/npm-audit-ci.sh`), never bare `npm audit`. Waivers: `scripts/npm-audit-allowlist.json`.
- CI: `.github/workflows/pr-checks.yml` runs the same checks as the hooks.

## Learned Workspace Facts

- **Stack:** static site for MTS Security (Augsburg / Bavaria), generated by a zero-dependency Node build (`npm run build` → `dist/`). Pages render from `src/pages/*.mjs` with the `html` tagged template (`src/lib/html.mjs`, auto-escaping). Never edit `dist/`; it is not committed.
- **Pages:** the homepage (`src/pages/home.mjs`, bilingual DE/EN via `script.js`), 2 hubs + 10 service pages generated from `src/content/` (German only), `/impressum`, `/datenschutz`, 404. Add a service by editing `src/content/security.mjs` or `facility.mjs`; see `docs/seo.md`.
- **SEO:** titles, descriptions, JSON-LD, sitemap and robots are generated; `npm test` enforces unique titles/descriptions, canonicals, schema, sitemap and link integrity. Guide: `docs/seo.md`.
- **Server code:** only `api/send-email.js`, a Vercel serverless function for the contact form. It sends via Hostinger SMTP with nodemailer and needs `EMAIL_USER` / `EMAIL_PASSWORD` (Vercel env vars, never committed).
- **Deploy:** Vercel Git integration deploys `master`; `vercel.json` sets the build, `outputDirectory: dist`, `cleanUrls`, redirects and headers. Domain `mts-sicherheit.com`; the apex → `www` redirect lives in the Vercel dashboard.
- **CSP:** `vercel.json` sets `default-src 'self'` with no inline scripts or styles (JSON-LD data blocks are fine). Keep JS in `script.js`, CSS in `styles.css` / `subpages.css`, and every asset self-hosted, or the page breaks in production only.
- **Assets:** CSS/JS are content-hashed into `/assets/` by the build (`src/lib/assets.mjs`); reference them with `asset('styles.css')`, never by literal path. Service-page photos come from `images/opt/` (AVIF), generated by `src/tools/optimize-images.sh` (macOS `sips`) and committed.
- **Local preview:** `npm run build && npx serve dist`. The contact form only works under `vercel dev` or on a Vercel deployment.
- **Copy:** user-facing text is German. Never add unconfirmed business facts (certifications, founding year, prices, availability). `/impressum` and `/datenschutz` still contain bracketed placeholders (register data, managing director, VAT ID).
- **Checks:** no ESLint or typecheck. `npm test` (node:test on the built `dist/`) and `npm run build` run in pre-push and CI, plus Knip and Prettier. Prettier skips embedded HTML in `src/` (`embeddedLanguageFormatting: off`) so templates are never reflowed. `styles.css` is over 600 lines (CSS is not in the file-size check).
